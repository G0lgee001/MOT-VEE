# 🌊 Ripplab - Müzik Pazar Yeri

Modern ve etkileyici bir müzik pazar yeri platformu. Beat'ler, ses efektleri, albüm kapakları ve daha fazlasını satın alabilir veya satabilirsiniz.

## ✨ Özellikler

- 🛒 **Alıcı/Satıcı Seçimi** - Ana sayfada iki ana seçenek
- 📁 **Kategori Sistemi** - Beat, FX, Kapaklar, Sample Packs
- 🔥 **Trend Müzikler** - En popüler ve yeni eklenenler
- 📋 **Nasıl Çalışır** - 3 basit adımda başlama
- 🎨 **Modern UI/UX** - Renk paletinizle tasarlandı
- 📱 **Responsive Tasarım** - Tüm cihazlarda mükemmel görünüm
- 🎵 **Müzik Önizleme** - Modal'larda müzik dinleme
- ⌨️ **Interactive** - Hover efektleri ve animasyonlar

## 🚀 Teknolojiler

- **HTML5** - Semantic markup
- **CSS3** - Modern CSS features (Grid, Flexbox, Animations)
- **JavaScript (ES6+)** - Modern JavaScript features
- **Font Awesome** - Icon library
- **Google Fonts** - Inter font family
- **CSS Variables** - Custom properties for theming
- **Intersection Observer API** - Scroll animations

## 🎨 Özelleştirme

### CSS Variables
Renk paletini değiştirmek için `css/style.css` dosyasındaki CSS variables'ları düzenleyin:

```css
:root {
    --primary: #0386f2;    /* Ana renk */
    --accent: #0047c4;     /* Vurgu rengi */
    --secondary: #6eafdf;  /* İkincil renk */
    /* Diğer renkler... */
}
```

### Logo Değiştirme
`assets/logo.png` dosyasını kendi logonuzla değiştirin.

### Müzik Verisi
`js/app.js` dosyasındaki `marketplaceData` objesini düzenleyerek kendi verilerinizi ekleyin.
